# Internationalization

- **Registry:** `src/i18n/locales.ts` declares every locale (code, native name, direction, tier, per-namespace status). Nothing else hardcodes language lists.
- **Resources:** `src/i18n/locales/<code>/<namespace>.json`, i18next JSON v4 (CLDR plural suffixes `_one`, `_many`, `_other`, …). Loaded lazily per locale/namespace.
- **Source locale:** `en`. **Fallback:** `en` for every locale; the UI shows a notice when a locale has missing namespaces.
- **Status:** `reviewed` (human-validated), `draft` (complete or partial, unvalidated — includes AI drafts), `missing`. Only a human reviewer may set `reviewed`; a test guards this. All locales are currently `draft`.
- **Snapshots store message keys + values**, never rendered text, so switching language never touches execution state.
- **Checks** (`npm run i18n:check`): unregistered files, status/resource consistency, missing and extra keys, placeholder mismatches, empty strings, required CLDR plural forms per language, and a coverage table.

## Adding a language

1. Add JSON files under `src/i18n/locales/<code>/` (copy `en`).
2. Set the namespaces' status to `draft` in `locales.ts`.
3. Run `npm run i18n:check`; fix all reported issues.
4. A qualified reviewer validates against `docs/GLOSSARY.md`, then status becomes `reviewed`.

## Feasibility of additional locales

All 13 are registered (status `missing`, hidden from the selector). Specific concerns:

| Locale | Notes |
|---|---|
| fr, it, nl, tr, id | Latin script; low risk. fr/it have a CLDR `many` plural form. tr: dotted/dotless i casing — never use `toUpperCase()` without locale. |
| pl, uk | Four plural categories (`one`, `few`, `many`, `other`); uk uses Cyrillic. |
| ja, ko, zh-Hans, zh-Hant | System CJK fonts via `:lang()` stacks; no word spaces — avoid layouts that rely on word breaking; keep zh-Hans/zh-Hant separate (terminology differs, not just script). |
| hi | Devanagari; needs adequate line height (already 1.55). |
| ar | RTL: layout uses logical CSS properties and `dir` is set on `<html>`. Six plural categories. The graph SVG itself stays LTR; queue/stack direction in RTL needs a pedagogical decision before enabling. |

Reviewed educational quality requires a native-speaking reviewer with CS background per locale.
